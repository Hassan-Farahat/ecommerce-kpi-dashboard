# 📊 E-Commerce KPI Dashboard

An interactive executive analytics dashboard built with Python and Streamlit to monitor sales revenue, profit margins, product category performance, and regional market distribution in real time.

🚀 **[Live Demo](https://hassan-farahat-ecommerce-kpi-dashboard-app-cwjdul.streamlit.app/)**

---

## ✨ Features

* **Executive Metrics:** Live tracking of Total Revenue, Total Profit, Order Counts, and Average Order Value (AOV).
* **Multi-Filter Controls:** Filter performance dynamically by Region and Product Category.
* **Monthly Revenue Trends:** Line visualization tracking historical performance over time.
* **Category Breakdown:** Interactive bar chart comparing sales volume across product lines.
* **Market Share Analysis:** Donut chart showcasing revenue concentration by global regions.

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit** (Web Application Framework)
* **Plotly Express** (Interactive Data Visualizations)
* **Pandas & NumPy** (Data Generation & Processing)
